# 0001 — Lock the sweater before the card, reuse it as a Reference Layer

Status: accepted (2026-11-20)

The Sweater Design is finished and exported before any card work starts, and the Finished Card copies it
from a Reference Layer instead of regenerating it from text. This spends the scarce Generation Budget
sequentially and means a late sweater idea forces card rework, but judges score whether the sweater and
card "work together", and a text-regenerated sweater would drift (different digits, motifs, colours).
