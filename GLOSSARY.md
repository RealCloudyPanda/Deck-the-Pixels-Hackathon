# Glossary

Terms used across the kit. Definitions only; how things are built lives in the docs.

**Sweater Design** — Image 1 of the submission: the finished ugly sweater on its own, as a flat-lay.
_Avoid_: sweater mockup, pattern.

**Finished Card** — Image 2 of the submission: the holiday card with the owner's likeness wearing the
Sweater Design. _Avoid_: final image, poster.

**Panda Self** — the owner's own likeness restyled into a messy brown panda look. The only likeness
allowed in either image. _Avoid_: character, model, mascot.

**Generation** — one Generative Fill run with Nano Banana selected as the model. The unit of the daily
budget. _Avoid_: render, roll, credit.

**Generation Budget** — the number of Generations available per day (5 on the free web tier).
_Avoid_: quota, credits.

**Generation Log** — the owner's record of every Generation: date, image, selection, model, prompt id,
kept or not. Source of every number in the Written Answers. _Avoid_: history.

**Joke Hierarchy** — the reading order of the joke, from what reads smallest to what rewards a close look.
_Avoid_: visual hierarchy (too general).

**Read Size** — the smallest displayed width at which a tier of the Joke Hierarchy is still understood.

**Reference Layer** — the approved Sweater Design placed inside the card canvas so Nano Banana can copy
it; hidden in the final file. _Avoid_: guide layer, template.

**Hand-set Lettering** — every word or number in the images, set as editable Photoshop type and never
generated. _Avoid_: AI text, generated text.

**Negative Clause** — the fixed sentence appended to every prompt that rules out text, logos and brands.

**Layers Screenshot** — the required screenshot of the Photoshop file with the Layers panel visible.

**Written Answers** — the required descriptions of how Nano Banana and Photoshop were used for each image.

**Production Kit** — this repository: brief, prompts, runbook, submission drafts and the Thumbnail Test.
It never contains contest images. _Avoid_: project, entry.

**Contest Asset** — any image submitted to Devpost. Made only by the owner. _Avoid_: deliverable.

**Composition Sketch** — a wireframe SVG in this repo that shows placement only; explicitly not a
Contest Asset.

**Thumbnail Test** — the local web tool that shows both images at small sizes and runs the Tally.

**Tally** — the 3-person "what's the joke?" check recorded in the Thumbnail Test.

**Sample Mode** — the Thumbnail Test running on the Composition Sketches instead of the owner's images.
